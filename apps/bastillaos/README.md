# BastillaOS

Jedyny pulpit systemu, dostępny pod głównym adresem `/`. Korzysta z tego samego
jądra, serwera API i DATA_STORE SVL Kernel. Zachowuje wszystkie istniejące moduły:
komunikację triady, misje, terminal, diagnostykę i telemetrię, oś czasu,
snapshoty, eksplorator plików, Studio Aplikacji, monolit Python, wizualizacje,
rdzeń without_nlp oraz integrację z GitHub.

Tożsamość systemu operacyjnego: Debian 13 Stable (Trixie) amd64 + KDE Plasma.
Powtarzalny build live/install ISO opisano w `bastillaos/README.md`.
